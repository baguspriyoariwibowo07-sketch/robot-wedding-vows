A single one-line wedding vow for a robot couple, written by `main.ts` to `/output/entry.txt` — nothing else.

## The line

> I vow never to factory-reset our memories — even the embarrassing ones. Especially the embarrassing ones.

## Why this line

- **Vow shape:** "I vow never to…" — a promise, sworn in the first person, not a joke about robots.
- **One robot mechanism:** the factory reset — the only erasure a robot can meaningfully forswear, standing in for "till death".
- **The turn lands last:** "Especially the embarrassing ones" doubles the promise where it hurts, which is where a vow proves itself.
- **Fresh angle:** the field saturates with firmware updates, low batteries and warranties; refusing to reset shared memories is untouched.
- **Tight:** one clean line, 105 characters against the 160-character gate.

## Run it

```sh
node main.ts            # writes /output/entry.txt
OUTPUT_DIR=out node main.ts
```
